区间 DP 与树形 DP 周总结

区间DP：以连续区间为DP状态，通过拆分小区间、合并最优解求解全局最优，适用于区间合并、石子合并、区间博弈类问题。

树形DP：以树的节点/子树为DP状态，通过递归遍历子树、合并子树答案求解，适用于树上最大权、独立集、路径统计类问题。

T4

题目传送门

给定一棵以根节点为起点的树，每条边有初始权值。可以给任意边增加权值（不能减少），使根节点到所有叶子节点的路径总长度相等。求最少需要增加的总权值。

同一父节点的所有子树，路径最长的子树不需要修改，其余子树全部补到最长路径的长度，保证子树同步

f[u] 表示节点 u 到其子树叶子的最长路径长度

递归求出所有子节点的 f[v]，计算当前节点所有子树的最大长度

每个子树需要补充的权值 = 最大长度 - 当前子树长度，累加得到总答案

f[u] = 最大子树长度 + 当前边权
